# Публикация демо Дантист-ЛК

Сайт переработан 10.10.2026. Шесть страниц на украинском языке.

1. Создайте в аккаунте **konkos-design** репозиторий **dantyst-lk**.
2. Загрузите содержимое папки сайта, сохранив папки css, js, img и fonts. Файл index.html должен лежать в корне репозитория.
3. В Settings → Pages выберите Deploy from a branch, ветку main и папку /(root). Нажмите Save.
4. После завершения публикации адрес будет: https://konkos-design.github.io/dantyst-lk/

Этот адрес уже прописан для карточки ссылки. Если имя репозитория изменится, нужно изменить og:url и og:image во всех HTML-файлах.

Для просмотра без GitHub откройте index.html двойным щелчком. Все страницы, фильтры, поиск и галерея работают без установки программ.

Демо содержит noindex, nofollow и запрет в robots.txt. Перед запуском купленного сайта на домене клиента удалите оба ограничения, обновите адреса карточки ссылки и подтвердите у клиники цены, график и материалы.

Промо находятся в отдельной папке preview/dantyst-lk и в _promo. Папку _promo не нужно загружать на GitHub.

Источники фактов и фотографий перечислены в SOURCES.md. Таблица лидов и Google Drive в этой задаче не изменялись.
